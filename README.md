# 🎡 Movie & Anime Decision Maker (Spin the Wheel)

An interactive, responsive digital picker wheel built to solve the ultimate developer dilemma: *"What should I watch next?"* Enter your favorite choices, hit spin, and let the wheel decide!

## 🛠️ Features
- **Dynamic Input Entry:** Add and remove custom options on the fly.
- **Custom Badge Rendering:** Interactive badge tags created seamlessly via Vanilla JavaScript DOM manipulation.
- **Smooth Physics Rotation:** Crafted using Tailwind transition behaviors combined with randomized JavaScript degree calculations.
- **English/Hindi Film Database Testing:** Optimized interface validated with blockbuster hits (e.g., Baaghi, Encounter, BusinessMan).

## 💻 Tech Stack
- **HTML5:** Basic structural architecture.
- **Tailwind CSS:** Modern utility-first dark layout framing.
- **Vanilla JavaScript:** Event loop tracking, Math configurations, and time interval execution.

## 🚀 How to Run Locally
1. Clone this repository.
2. Open `index.html` in your browser or run via VS Code **Live Server**.
